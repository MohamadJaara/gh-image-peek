# Reporting security issues

Use **Security → Report a vulnerability** in this GitHub repository to send a private report when private vulnerability reporting is enabled. Include the affected extension version, browser/version, reproduction steps, and the expected versus actual behavior.

If the private reporting option is unavailable, open an issue asking the maintainer for a private contact channel, without disclosing vulnerability details or sensitive data.

Keep API credentials, session tokens, private GitHub content, and other users' information out of public issues and pull requests. Review screenshots and logs before attaching them. General bugs and feature requests can use normal GitHub issues.
